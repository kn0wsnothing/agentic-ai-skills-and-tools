# deep-research-vibe-coding

A ready-to-run deep research prompt for investigating best practices in AI-assisted ("vibe coding") web app development — written for builders who have no formal programming background but are comfortable thinking and iterating with AI tools.

## What it's for

Use this when you want a rigorous, methodology-grounded guide to building functional web app prototypes with LLM assistance — one that covers the full arc from ideation and scoping through architecture, debugging, deployment, and the psychological dynamics of learning-through-building.

The prompt explicitly targets platform-agnostic principles, not tool-specific walkthroughs. The output should be applicable regardless of which AI coding tool, visual builder, or deployment platform you use.

## How to use it

Paste `PROMPT.md` directly into a deep research tool (ChatGPT Deep Research, Gemini Deep Research, Perplexity, etc.) as the research prompt.

The "iteration plan" section at the end suggests validating initial findings against a simple sample project brief (e.g., a to-do app, journaling app). If you want the research to validate against a specific project you have in mind, add a brief description of that project at the end of the prompt.

## What to expect

A structured report covering:
1. A working definition of vibe coding and its actual limitations for non-coders (not marketing speak)
2. A survey of related methodologies: no-code, low-code, LLM-driven development, and human–AI pair programming
3. Key principles for effective AI collaboration — prompt clarity, iterative refinement, role switching between AI-as-architect and AI-as-debugger
4. Frameworks for planning app structure before writing a single line of code
5. Common pitfalls (scope creep, dependency errors, deployment barriers) and how to prevent them
6. A recommended workflow from ideation to prototype launch with checkpoints
7. A learning and reflection model for progressively building real technical understanding, not just prompt fluency

The output goal is a practical, mindset-oriented guide — specific enough to act on, honest about where vibe coding breaks down.
