# End-of-day wrap

A minimal EOD routine prompt. Reviews what happened today, organizes it into four buckets, surfaces tomorrow's top three priorities, and drafts a shareable daily note.

## What it's for

Closing the loop at end of day without turning it into a project. Takes the context of what you've been doing (tabs, tasks, conversations) and turns it into a clean handoff — useful both for personal reflection and for communicating progress to a team.

## How to use

Paste `PROMPT.md` as the system prompt in an AI assistant that has access to your current context — open tabs, task list, recent work. Or paste in a rough brain-dump of what you did and let the model organize it.

Works well as a daily recurring prompt, or as a quick end-of-session cleanup.

## What to expect

- A structured summary: completed / in progress / resources to revisit / open questions
- Three prioritized tasks for tomorrow
- A short (5-bullet max) daily note ready to share via message or email

## Notes

This is intentionally minimal — the value is in the habit, not the length. If you want a heavier end-of-day review with journaling or weekly synthesis, pair it with a more structured daily review workflow.
