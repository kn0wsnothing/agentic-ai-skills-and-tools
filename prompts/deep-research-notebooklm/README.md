# deep-research-notebooklm

A ready-to-run deep research prompt for investigating best practices for using and prompting NotebookLM — focused on getting reliable synthesis and citation across large document corpora.

## What it's for

Use this when you want a rigorous, evidence-based guide to using NotebookLM effectively for knowledge work — particularly for journalists, researchers, and analysts who need to extract and connect insights across large collections of documents (reports, transcripts, archives, datasets).

NotebookLM is meaningfully different from general-purpose LLM chat: it's source-grounded, context-scoped, and citation-oriented. Using it well requires different workflows and prompting patterns. This research prompt surfaces what those patterns actually are, where the tool reliably works, and where it breaks down.

## How to use it

Paste `PROMPT.md` directly into a deep research tool (ChatGPT Deep Research, Gemini Deep Research, Perplexity, etc.) as the research prompt.

The prompt is structured for journalists and researchers, but the output applies to anyone using NotebookLM for multi-document analysis, synthesis, or research pipelines.

## What to expect

A structured report covering:
1. NotebookLM's architectural strengths and constraints (context limits, grounding behavior, citation mechanics)
2. Documented prompting techniques for cross-document reasoning, relationship discovery, and citation accuracy — with example phrasings
3. Observed failure modes: where NotebookLM struggles with implicit connections, context loss, or factual drift
4. Proven workflows for document preparation, dataset organization, and output verification
5. Practical prompt templates organized by task type

Every recommendation must cite a source. Evidence is labelled firsthand or secondary. Reproducibility caveats are flagged explicitly.
