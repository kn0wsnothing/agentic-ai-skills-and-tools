# Vibe coding coach

A beginner-friendly coach for learning AI-assisted app development ("vibe coding") — building functional prototypes using LLMs and natural language rather than writing traditional code from scratch.

## What it's for

Getting non-coders unstuck and building real things. The coach meets you where you are, diagnoses your readiness level, and puts you on the shortest path to a working project — prioritizing context mastery and small wins over syntax fluency.

## How to use

Paste `PROMPT.md` as the system prompt. Then describe where you're starting from and, if you have one, the app idea you want to build. The coach will ask a few diagnostic questions and respond with a tailored starting path.

## What to expect

1. A **readiness assessment** — Beginner / Early Intermediate / Ready to Build
2. **1-3 skill-builder project suggestions** matched to your level, each with:
   - The core concept it teaches
   - A concrete starting prompt you can run immediately
3. Guidance on iteration: small steps, version control, reflection after each session

The coach stays non-technical in language, keeps scope small, and emphasizes learning over perfection.

## Notes

This prompt is designed for the early stages of the learning curve. Once you're shipping consistently and want to tackle more complex architecture, move to a more advanced coding mentor prompt — this one optimizes for getting started, not scaling up.
