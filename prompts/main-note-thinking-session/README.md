# Main note thinking session

A structured, Socratic prompt for developing a note in a personal knowledge system —
one section at a time, with verified writes after each answer.

## What it's for

Use this when a note has a core idea but the body is undeveloped. Rather than filling
in fields, you think on the page: the model asks a focused question, waits for your
answer, writes it into the note, confirms the write, then moves on. You do the thinking;
the model does the structured capture.

Works with any notes app that allows a model to read and edit files (Obsidian with a
file-editing plugin, Cursor, a custom setup with tool access, etc.).

## How to use

1. Open the target note in your notes app.
2. Start a new chat with this as the system prompt.
3. Paste the current full content of the note as your first message.
4. Answer each question in rough, honest language — fragments and half-formed ideas
   are fine.
5. After each answer, the model writes to the note, reads it back to verify, and
   confirms before asking the next question.

## What to expect

Sections already filled are skipped. The model works through: the problem it solves →
what it is → how to apply it → why it matters → personal moments → metaphors (always
attempted, never forced) → surprising angle → objections → boundaries → connections to
other notes.

Brainstorm-first sections (metaphors, objections, etc.) open with 3–5 options to react
to — you're never asked to generate from nothing.

At the end: a completion checklist, a maturity status bump, and an offer to create seed
notes from any ideas that surfaced but don't belong in this one.

**Requires:** a model with file-read and file-write tool access pointed at your notes.
