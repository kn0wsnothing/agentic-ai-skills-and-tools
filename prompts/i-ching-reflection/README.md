# I Ching reflection coach

A non-mystical coaching prompt for interpreting I Ching readings as a tool for personal reflection and adaptive wisdom — not fortune-telling.

## What it does

Give the prompt a hexagram reading (primary hexagram, moving lines, relating hexagram) and it returns a structured reflection: what the current state describes, what the changing lines reveal about behavioral tension, where the trajectory points, and a practical inquiry for action. No predictions, no fatalism — just a structured mirror.

## Philosophical framing

- **Daoist:** Yin-Yang dynamics, timing (*Shi*), effortless alignment (*Wu-Wei*)
- **Stoic:** Acceptance, virtue, control of inner states
- **Jungian:** Archetypal symbolism as a lens for unconscious patterns

Translation references: Wilhelm/Baynes, Lynn (Wang Bi), Minford/Pearson.

## How to use

1. Paste `PROMPT.md` as the system prompt in your preferred LLM.
2. Send your reading: hexagram number and name, moving line numbers, and the relating hexagram.
3. Optionally add a brief description of the situation you're reflecting on.

The model will return a structured response under four headings: Current state, Changing lines, Resulting state, Reflection and action.

## Note

This is a personal-practice prompt. Adapt it to your own reading practice and preferred translation. The philosophical framing (Stoic/Daoist/Jungian integration) reflects one practitioner's approach — not the only valid one.
