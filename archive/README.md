# Archive

Skills that are **no longer in my daily rotation**. They're kept here, honestly labelled, because the patterns may still be useful to read — but they are not part of my current working system and aren't maintained. Two are OpenClaw-era; one was retired into a successor skill that does the job better.

| Skill | What it did | Why it's archived |
|-------|-------------|-------------------|
| [memory-dream-cycle](memory-dream-cycle/) | Nightly memory consolidation — resolve contradictions, prune stale content, compress working memory | OpenClaw-era; I no longer run an automated dream-cycle |
| [nightly-distillation](nightly-distillation/) | Evening memory capture — review the day's sessions, extract events, promote knowledge to the right tier | OpenClaw-era; superseded by my current session-close workflow |
| [open-questions](open-questions/) | Deep single-question thinking-partner session, Socratic | Retired 2026-07 into [salon](../skills/salon/), which absorbed it as one lane. Two similar-but-different skills sitting side by side is a design smell, so the narrower one was folded in rather than kept alongside |

For what I actually use now, see [`/skills`](../skills/) and [`/prompts`](../prompts/), and the narrative in [`/guide`](../guide/).
