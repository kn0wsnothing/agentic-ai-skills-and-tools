# The system

This is the narrative companion to the catalog. The [`skills/`](../skills/) and [`prompts/`](../prompts/) directories are the parts; this is how they fit together into a way of working.

It's described in **roles, not products** — a thinking/prose agent, a data agent, and a shared memory both read and write. My particular tools are one instantiation. Swap in yours and the shape holds.
